# vdma-lif

Rust types for the **LIF (Layout Interchange Format) version 2.0.0** of the VDMA: track layouts (nodes, edges, stations, per robot type) as JSON.

Status: work in progress (skeleton only).

Source: [Intralogistics-2X-LIF/Layout-Interchange-Format](https://github.com/Intralogistics-2X-LIF/Layout-Interchange-Format) (VDMA e. V., MIT).
